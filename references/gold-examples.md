# Gold 模式库（WorkBuddy 适配版）

从最接近的组合模式起手，再改。每个模式都带"何时用"与"构图要点"。原版 `examples/` 是研究真实产品（Figma / Linear / Spotify…）得来的，这里转成 HTML/CSS 可落地的构图。

## hero-demo（英雄演示）
- **何时用**：官网 / 落地页首屏。
- **要点**：左文右图；右侧一个会"呼吸"或缓慢浮动的圆形/产品对象；一个**卫星卡片**跨骑在右缘（如"今日的练习 19:30 · 余 3 席"）；底部署名 stat 三连。
- **因果**：呼吸 = 品牌气质（calm）；卫星卡 = 把视线引向"现在发生的事"。

## bento（功能网格）
- **何时用**：课程 / 功能 / 卖点罗列。
- **要点**：一个 feature 大格（跨 2×2）+ 若干小格；每格一个标签 chip + 标题 + 一句描述；用微妙色调差（非多强调色）区分，避免"扁平"。
- **因果**：大格 = 主推；小格 = 同等重要但次要。

## dark-hero（深色英雄）
- **何时用**：高端、夜间、科技感。
- **要点**：纯黑底，靠 surface 台阶制造深度；一个被点亮的颜色；一个**自主变化的状态 pill**（如"在线"）。

## corner-chip（角标）
- **何时用**：想强调一个次要但相关的信息。
- **要点**：一个小 chip 居中压在窗口的某个角上，一半在窗外——制造"贴上去的真实感"而非装框。

## overlapping（重叠窗口）
- **何时用**：展示"设置改了什么"或主从关系。
- **要点**：一张卡浮在窗口前面，卡的边缘压在窗口的侧栏线上；一条引线从设置指向被改变的元素。

## device-pair（设备对）
- **何时用**：手机 + 大屏讲同一件事（如预约确认推送到手机）。
- **要点**：手机跨骑在大屏的 margin 上，**永远不要压在主角身上**；两者讲同一个事件。

## feature-grid（功能网格，图文）
- **何时用**：产品能力清单。
- **要点**：一 hero 图 + 一窗口 + 一个 stat + 一个对象 + 一个 diagram，错落排布；图形承担信息，不只装饰。

## stat-roll（数字滚动）
- **何时用**：关键指标。
- **要点**：数字在可见动作时滚动到位（用 CSS 计数或 transform），其余保持安静；只滚"当天的值"。

## 起手建议
不确定时用 **hero-demo + bento** 组合：首屏讲一个故事，下方用 bento 展开。绝大多数官网/落地页都能覆盖。
