# 五种翻车形态与修复（HTML/CSS 视角）

Stageshow 把 agent 做 UI 最常翻车的五种形态钉死。每做一个界面，对照自检。

## 1. 太满（Too Much）
**表现**：每个格子都是真实长文案、数字堆满，细节越多越像生成的。
**修复**：
- 真实文字只留给**故事焦点**（标题、1 个关键数据、1 个 CTA）。
- 其余区域用**占位条**（灰色细条）或留白；列表下方、面板边缘允许"从容的空"。
- 控制"真字符串预算"：一段界面里真实可读的句子不超过 3–5 处。

## 2. 线框（Wireframe）
**表现**：两个灰块 + 一个按钮，被剥除了可辨识的产品特征，读不像产品。
**修复**：
- 给**完整且结构化的屏幕**：真实底色调、分组、图标、状态点。
- 即便简化，也要保留"它是什么产品"的最小信号（如课程名、时间、余席）。

## 3. 装框（Boxed）
**表现**：把整个窗口等比缩进一张四周等距的卡片里，像贴上去的截图，不像产品展示图。
**修复**：
- 让元素**跨骑边缘 / 重叠 / 出血**：卫星卡片压在 hero 边缘、图跨出容器、次要对象叠在主角旁边。
- 用 `overflow: visible` 与负 margin 制造"生长出画框"的感觉。

## 4. 扁平（Flat）
**表现**：所有物件同一视觉权重、同一带边框卡片，视线无处聚焦。
**修复**：
- 用**尺度、色彩、阴影、留白**拉开层级：一个 feature 大格 + 若干小格；主 CTA 实心、次 CTA 描边。
- 给画面一个明确的"主角"和一个安静的"配角"。

## 5. 平淡（Bland）
**表现**：brief 写了玻璃 / 蓝图 / Dynamic Island / 品牌色，结果只给一个灰窗口 + 一支光标，能量全没兑现。
**修复**：
- 拿到 brief **先定"外观"和"一个强调色"**，并贯穿全篇。
- 把品牌的视觉能量（色调、材质、圆角、一个吉祥物 / 图形符号）明确落到结构上，而不是留到"以后再说"。
